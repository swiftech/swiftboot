# SwiftBoot-Auth

提供 Web 应用开发中的用户认证功能


## 开发指南

[v3.md](docs/v3.md)

### 版本

* 稳定版

```xml
<dependency>
    <groupId>com.github.swiftech</groupId>
    <artifactId>swiftboot-auth</artifactId>
    <version>3.1.5</version>
</dependency>
```

* 不稳定版

```xml
<dependency>
    <groupId>com.github.swiftech</groupId>
    <artifactId>swiftboot-auth</artifactId>
    <version>3.2.0</version>
</dependency>
```

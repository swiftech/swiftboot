# swiftboot-service（试验）
提供 Web 开发中常见的服务

## 特性
* Captcha 服务，实现基于文本的防机器人验证码


## 开发指南

[v3.md](docs/v3.md)

## 版本

* 稳定版

```xml
<dependencies>
	<dependency>
		<groupId>com.github.swiftech</groupId>
		<artifactId>swiftboot-service</artifactId>
		<version>3.1.5</version>
	</dependency>
</dependencies>
```

* 不稳定版

```xml
<dependencies>
	<dependency>
		<groupId>com.github.swiftech</groupId>
		<artifactId>swiftboot-service</artifactId>
		<version>3.2.0</version>
	</dependency>
</dependencies>
```

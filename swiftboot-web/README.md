# SwiftBoot-Web
Web 应用开发的核心模块，依赖于 SwiftBoot-Data。


## 开发指南

[v3.md](docs/v3.md)

## 版本

* 稳定版

```xml
<dependencies>
	<dependency>
		<groupId>com.github.swiftech</groupId>
		<artifactId>swiftboot-web</artifactId>
		<version>3.1.5</version>
	</dependency>
</dependencies>
```

* 不稳定版

```xml
<dependencies>
  <dependency>
    <groupId>com.github.swiftech</groupId>
    <artifactId>swiftboot-web</artifactId>
    <version>3.2.0</version>
  </dependency>
</dependencies>
```

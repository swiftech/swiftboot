# SwiftBoot-utils 
企业应用开发常用工具类

---

## 功能

### org.swiftboot.util.AnnotationUtils
通过反射处理 Java 注解的工具类

* `<T extends Annotation> T getMethodsAnnotation(Object targetClass, Class<T> annoClass)` - 获取包含指定注解类型的方法的注解
* `List<Method> getMethodsContainsAnnotation(Object targetClass, Class annoClass)` - 获取包含指定注解类型的方法列表
* `Annotation getFieldAnnotation(Field field, Class annotationClazz)` - 获取指定 Field 中的指定类型的注解实例
* `<T extends Annotation> List<T> getMethodParamAnnotations(Method method, Class<T> annotationClass)` - 获取方法参数上的限定类型的所有注解

### org.swiftboot.util.BeanUtils
通过反射机制操作对象

* `List<Field> getDeclaredFields(Object object, Class<?> fieldClass)` - 循环向上转型，获取对象声明的字段
* `List<Field> getDeclaredFields(Class<?> clazz, Class<?> fieldClass)` - 循环向上转型，获取类声明的指定类型的字段列表
* `Field getDeclaredField(Object object, String propertyName)` - 循环向上转型，获取对象声明的指定名称的字段
* `Field getDeclaredField(Class<?> clazz, String propertyName)` - 循环向上转型，获取类声明的指定名称的字段
* `Collection<Field> getAllFields(Class<?> clazz)` - 获取类的所有字段
* `Collection<Field> getFieldsIgnore(Class<?> clazz, Collection<String> ignoreFields)` - 获取忽略指定字段的类字段
* `Collection<Field> getFieldsIgnore(Class<?> clazz, String... ignoreFields)` - 获取忽略指定字段的类字段
* `<T> List<T> forceGetProperties(Object object, Class<T> returnType)` - 强制获取对象的所有属性
* `Map<String, Object> forceGetProperties(Object object)` - 强制获取对象的所有属性为Map
* `Object forceGetProperty(Object object, String propertyName)` - 强制获取对象的指定属性
* `Object forceGetProperty(Object object, Field field)` - 强制获取对象的指定字段
* `void forceSetProperty(Object object, String propertyName, Object value)` - 强制设置对象的指定属性
* `void forceSetProperty(Object object, Field field, Object value)` - 强制设置对象的指定字段
* `void forceSetPropertyFromString(Object object, String propertyName, String value)` - 强制设置对象的指定属性值
* `void forceSetPropertyFromString(Object object, Field field, String value)` - 强制设置对象的指定字段值
* `void forceSetProperties(Object object, Map<String, Object> properties)` - 强制设置对象的多个属性
* `Object forceInvokeMethod(Object object, String methodName, Object... args)` - 强制调用对象的方法
* `List<Field> getDeclaredFieldsByAnnotation(Class<?> clazz, Class<? extends Annotation> annotationClass)` - 获取具有指定注解的字段
* `List<Field> getDeclaredFieldsByType(Object object, Class<?> fieldType)` - 获取指定类型的所有字段
* `List<Field> getDeclaredFieldsByTypeIgnore(Object object, Class<?> fieldType, String... ignoreFields)` - 获取指定类型的所有字段并排除某些字段
* `List<Field> getStaticFields(Class<?> clazz)` - 获取类的所有静态字段
* `List<Field> getStaticFieldsByType(Class<?> clazz, Class<?> fieldType)` - 获取指定类型的静态字段
* `Class<?> getPropertyType(Class<?> clazz, String propertyName)` - 获取属性的类型
* `<T> List<T> getPropertiesByType(Object object, Class<T> propertyType)` - 获取指定类型的属性值
* `String getGetterName(Class<?> clazz, String propertyName)` - 获取属性的getter方法名称

### org.swiftboot.util.BitUtils
二进制位操作

* `<T extends Number> contains(T target, T body)` - 判断一个数字的二进制位是否和另外一个数字的二进制位重叠
* `long bitwiseOr(Collection<Long> longs)` - 对集合中的所有长整数做逻辑或操作，相当于合并所有二进制位

### org.swiftboot.util.BooleanUtils
布尔值工具类

* `Boolean or(List<Boolean> list)` - 对布尔值列表执行或操作
* `Boolean or(Boolean... array)` - 对布尔值数组执行或操作

### org.swiftboot.util.BufferedIoUtils

* `String readAllAsString(InputStream in)` - 从输入流读取所有字符串
* `void readFrom(InputStream in, int bufSize, Consumer<byte[]> consumer)` - 读取输入流数据到缓存并通过回调返回给调用者
* `void writeInputStreamToFile(InputStream in, int bufSize, File targetFile)` - 将输入流的数据写入文件中

### org.swiftboot.util.I18nHelper
国际化辅助类

### org.swiftboot.util.IdUtils
ID工具类，生成UUID，业务ID，流水号等

* `String makeUUID()` - 生成不包含'-'分隔符的 UUID，长度固定为32字节
* `String makeID(String bizCode)` - 通过业务码生成全局唯一 ID
* `String makeID(String bizCode, String serverId)` - 通过业务代码和服务器ID生成UUID
* `String makeSn()` - 以当前时刻生成流水号，长度固定为17字节
* `String makeSnRandom()` - 以当前时刻+三位随机数生成流水号，长度固定为20字节

### org.swiftboot.util.ImageUtils
处理图片的工具类

### 时间相关的工具类

* `String toCronExpression(LocalDateTime dateTime)` - 从 LocalDateTime 生成 Spring 兼容的 cron 表达式
* `String toCronExpression(Integer month, Integer day, Integer hour, Integer minute, Integer second)` - 通过给出月，日，时，分，秒构建CRON表达式，如果任何变量给出null值的话转换成`*`
* `String toCronExpression(Integer day, Integer hour, Integer minute, Integer second)` - 通过给出日，时，分，秒构建CRON表达式，如果任何变量给出null值的话转换成`*`, 月份永远是`*`
* `toCronExpression(Integer hour, Integer minute, Integer second)` - 通过给出时，分，秒构建CRON表达式，如果任何变量给出null值的话转换成`*`, 月份，日期永远是`*`
* `toCronExpression(Integer minute, Integer second)` - 通过给出时，分，秒构建CRON表达式，如果任何变量给出null值的话转换成`*`, 月份，日期，小时永远是`*`
* `toCronExpression(Integer second)` - 通过给出秒构建CRON表达式，如果给出null值的话转换成`*`, 月份，日期，小时，分永远是`*`
